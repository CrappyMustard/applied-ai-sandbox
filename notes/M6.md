Cursor is cool for tiny, non-essential work that requires quick programming; It may not work well with bigger, more complex code and assignments.

## Gemini CLI Comparison

## ChatGPT Comparison

When inputting, Chat found that the function involving "pytest" was worded slightly differently compared to the rest of the M5; that may be something a junior dev should notice.

## Tool Decision Matrix

Essentially, Claude is good for deeper, analytical coding with big programs; Cursor is great for smaller and less accident-prone coding with pieces of code; Gemini is good for more to-the-point programming; ChatGPT is good for finding flaws and refining (although user verification is still key here).
