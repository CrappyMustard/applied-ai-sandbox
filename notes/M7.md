## Plan from Chat

Feature: My planned feature is to design a note search function that can scour through both titles and body text.

Design from Chat:

- Apply Interface changes.
- Search input in notes header.
- Persistent text field (not a modal/overlay).
- Debounced requests (300 ms).
- Fire API call after user pauses typing. Cancel in-flight request when new keystroke arrives.
- Highlighted snippets in result rows.
- Show body excerpt with matched terms wrapped in <mark>. Truncate to ~120 chars around first match.
- URL reflects query.
- Sync ?q= to address bar via history.replaceState so searches are shareable and survive reload.
